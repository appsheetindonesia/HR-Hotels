# Rotela — Paket Dokumen Requirements

Paket ini berisi sembilan dokumen kebutuhan untuk membangun aplikasi HR dan shift management berdasarkan referensi Rotela.

> **Penting:** Tautan tujuan pada permintaan adalah `https://demo.codeandchill.store/rotela/` (Rotela, aplikasi HR/rota), meskipun label tautannya menyebut `konveksi.toko-abi.com`. Paket ini mengikuti URL tujuan. Bila maksudnya aplikasi konveksi, referensi harus diganti dan dokumen ini tidak boleh dipakai sebagai spesifikasi konveksi.

## Daftar dokumen

1. Market Requirements Document (MRD).md
2. Customer Requirements Document (CRD).md
3. Business Requirements Document (BRD).md
4. Product Requirements Document (PRD) 18 Section.md
5. User Interface Requirements Document (UIRD).md
6. Functional Requirements Document (FRD).md
7. Technical Requirements Document (TRD).md
8. Quality Requirements Document (QRD).md
9. Software Requirements Specification (SRS).md

Dokumen ditulis dalam Bahasa Indonesia. Sumber fitur: [Demo Rotela](https://demo.codeandchill.store/rotela/) dan [spesifikasi resmi Rotela](https://codeandchill.store/templates/rotela). Detail visual pixel-level tetap perlu diverifikasi langsung pada seluruh halaman dan state demo sebelum menyatakan lulus 100% identik.
